# \# FORMA

# 

# FORMA is a quiz and study desktop application built with Python Tkinter.

# 

# \## Current Features

# 

# \- Desktop interface with sidebar navigation.

# \- Explore Quizzes screen with FORMA's custom theme.

# \- User registration and sign-in through the backend API.

# \- Profile menu with account information and logout.

# \- Additional quiz and study features under development.

# 

# \## Requirements

# 

# \- Python 3.10 or later.

# \- Tkinter.

# \- FORMA backend for registration and sign-in.

# 

# \## Run on Windows

# 

# Open Command Prompt in the repository root and run:

# 

# ```cmd

# python -m desktop\_app.main

# ```

# 

# To verify Tkinter is available:

# 

# ```cmd

# python -c "import tkinter; print('Tkinter is working')"

# ```

# 

# \## Backend Setup

# 

# Start the FORMA backend separately. The desktop application expects the API at:

# 

# `http://localhost:5000/api/v1`

# 

# Registration and sign-in require the backend to be running.

# 

# \## Development Status

# 

# The Home screen, subject-wise quiz browsing, and additional study features are still being developed. Unimplemented features may display placeholders.
